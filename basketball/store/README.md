# Arcade Hoops 街机投篮机

第一视角的街机投篮机：60 秒限时刷分，尽量多投进球，冲击最高分（BEST）。上手快、节奏爽，越到最后越刺激。

## 玩法

- **投篮**：向上滑动并松手出手；滑得太短（轻点）不会出手。
- **瞄准**：上滑时的横向偏移决定方向；注意侧风会把球吹偏。
- **力度**：上滑距离决定力度——太短偏软、太长偏冲。
- **球架**：开局 5 颗球，出手后立即补到手中，球架约每秒回一颗。
- **篮筐与球值**：当前版本固定为中距离篮筐，基础命中得 2 分。
- **连击 COMBO**：连中 3 个及以上，每球额外 +1 分。
- **FEVER 疯狂模式**：最后 20 秒篮筐左右滑动、所有进球得分翻倍（x2），全靠手速抓时机。
- **结算**：时间到显示最终分、最高分（NEW BEST 高亮）、命中率与最长连击，点按再来一局。

## 特色

- 街机风格的第一视角投篮体验，支持多球同时飞行。
- 真实球、篮筐和球场图集结合图元 HUD，直接写入 480×480 RGB565 帧缓冲。
- 程序化音效，投篮、命中、连击、FEVER 各有反馈。
